KNI run manifest format (actual, from engine/pipeline/src/main.rs parse loop @ PR 84fbe2fa).
Line-based, one key per line, fields space/tab-separated. Keys used by the fixtures here:

  run_mode full|stage1_only     full = fit+spacing+OTF; stage1_only = fit only, stops before spacing
  family / subfamily / postscript_name <str>
  vendor <str|NONE>
  upm <int>                     units per em (1000)
  scale <float>                 px->font-units scale for this style
  population_sha256 <64hex>     pin over the parsed glyph rows: rows "<seq>:<name>\n" (seq = hex codepoint,
                                ligatures joined by _, unencoded rows keyed "anon:<name>"), sorted, sha256 of concat
  capture_cohort / capture_frame <id>
  fit_tolerance_policy fixed|measured_experimental|derived_source_quantization
  fit_squared_error <float>     fixed-route tolerance
  fit_max_refits <int>
  flatten_tolerance <float>
  rdp_epsilon <float>
  corner_wiring on|off
  glyph <cp> <name> <image> [scale]    encoded row; cp hex (0x0021), ligature cps joined by _
  glyph - <name> <image> [scale]       UNENCODED anonymous row: drawn/fitted/spaced, ships in the CFF charset
                                       with NO cmap entry; name charset [A-Za-z0-9_.] (hyphen refused, row-excluded)
  auto_sb median|class          sidebearings from pool/class table instead of fixed baseline (kit: additive, off default)
  auto_sb_pool <path>           pool TSV, header: left_class<TAB>right_class<TAB>lsb<TAB>rsb ('empty' = none)
  auto_sb_class_table <path>    class mode only; dangling in median mode = refusal
  tie_break A|B                 required with auto_sb; even-n median rule, explicit only

Row-local value faults exclude only that row (typed manifest_row_excluded event); the run continues.
Population pin mismatch under run_mode full = refusal (a shard cannot run spacing).
